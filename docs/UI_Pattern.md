# UI Pattern – Project Operations System

## Core Principles

- Table-based UI
- Inline creation
- No modals
- No complex forms
- Server actions only

---

## Table Pattern (MANDATORY)

Each table follows:

- Header row
- Inline creation row OR expandable row
- Rows editable inline
- Actions inside last column

---

## Styling Rules

- Consistent row height
- Vertical column alignment
- Clear headers
- Clickable navigation in blue + underline

---

## Interaction Rules

- Create → inline
- Update → inline
- Delete → button in row
- Toggle → inline action

---

## Timeline (Gantt)

### Colors

- Grey → planned
- Light blue → in progress
- Blue → completed
- Red → delay

### Behaviour

- Group by phase
- Expand / collapse
- Phase = roll-up of workstreams
- Delay = visual + numeric
- Today line always visible

---

## Navigation

- Lists → detail pages
- Clickable names (blue + underline)
- No hidden navigation
